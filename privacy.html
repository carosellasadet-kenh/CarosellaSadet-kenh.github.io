Privacy Policy – YT Auto Upload

Last updated: October 30, 2026

What the app accesses

When the owner connects a YouTube channel, the app requests permission to manage that channel through the YouTube Data API (scopes: youtube, youtube.upload, youtube.force-ssl). It uses this access only to: read the channel's ID, title and handle; list the channel's recent uploads and playlists to avoid duplicate uploads and to pick free publishing dates; upload videos and Shorts; set titles, descriptions, tags, thumbnails, captions, playlists and scheduled publishing times.

How data is stored

OAuth tokens, settings and upload logs are stored only on the owner's own computer (in the folder ~/YTAutoUpload). The app has no server, does not collect analytics and does not send any Google user data to anyone other than Google's own YouTube API.

Sharing

Google user data is not sold, shared, transferred to third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, or by choosing "Disconnect channel" in the app, which deletes the stored token from the computer.

Contact

Questions can be sent to the support email shown on the Google consent screen for this app.
